# Vici для Windows

Настольная версия — это та же веб-сборка приложения, упакованная в Electron.
Отдельного кода интерфейса здесь нет: `main.js` поднимает локальный http-сервер,
отдаёт из него `desktop/web` и показывает в окне.

## Запуск при разработке

```
npm run desktop
```

Команда из корня проекта собирает веб-версию, переносит её в `desktop/web`
и запускает Electron. Пересобирать нужно после каждой правки в `app/` —
живой перезагрузки здесь нет.

## Сборка установщика

```
npm run export:desktop
```

Результат — `desktop/release/Vici-Setup-<версия>.exe`.

Если сборка падает с `EPERM: operation not permitted, rename ... win-unpacked.tmp`,
значит антивирус держит только что распакованный электрон и не даёт переименовать
папку. Лечится либо исключением для папки проекта в защите в реальном времени,
либо сборкой в другое место:

```
npx electron-builder --win --publish never --config.directories.output=C:\temp\vici
```

На windows-раннере GitHub Actions этой проблемы нет.

## Что даёт обёртка

- **Медиа-клавиши и карточка трека в панели громкости Windows.** Работают без
  единой строчки в интерфейсе: страница уже выставляет `navigator.mediaSession`
  в `app/utils/player.web.js`, а `main.js` включает `HardwareMediaKeyHandling`
  и `MediaSessionService`, которые Electron по умолчанию держит выключенными.
- **Сворачивание в трей.** Крестик прячет окно, музыка продолжает играть,
  выход — через меню иконки в трее.
- **Автообновление** через `electron-updater` с GitHub Releases.
- **Скробблинг Last.fm.** `ws.audioscrobbler.com` не разрешает запросы со
  страницы, поэтому `main.js` дописывает заголовок `Access-Control-Allow-Origin`
  для этого адреса. В обычном браузере скробблинг с веб-версии работать не будет.

## Чего в настольной версии нет

Визуализатор butterchurn, автозапуск при подключении наушников и виджет — всё это
опирается на нативный модуль `modules/audio-route`, который написан под Android.
На вебе `requireOptionalNativeModule` возвращает `null`, обёртки отдают `false`,
и эти возможности просто не показываются.

Визуализатор при желании можно оживить отдельно: сам butterchurn — веб-библиотека,
и в браузере волну ему можно отдать напрямую из `AnalyserNode` Web Audio,
без всякого нативного модуля.

## Версии

Теги проекта выглядят как `v2026.09.20` или `v2026.09.20.3`, а electron-updater
понимает только semver, где ведущие нули и четвёртая часть недопустимы.
`version-from-tag.js` переводит одно в другое: `2026.09.20` становится
`2026.920.0`, а `2026.09.20.3` — `2026.920.3`. Внутри года версии так растут
по возрастанию, а с нового года увеличивается старшая часть.

Версию в `desktop/package.json` правит сборка на GitHub Actions, вручную её
менять не нужно.
